# Taxonomy размеров транспорта

Статус: черновик для согласования. Обучение и production-классификация запрещены до утверждения владельцем данных.

Класс определяется по типу и назначению транспортного средства, а не по видимому размеру bounding box. Перспектива, дистанция и загрузка не должны менять класс.

## Предлагаемые классы

### `light`

Легковые автомобили и сопоставимый лёгкий транспорт: sedan, hatchback, station wagon, coupe, compact SUV/crossover, minivan и малый пассажирский van при однозначной идентификации.

### `medium`

Промежуточный коммерческий/пассажирский транспорт: крупный van/minibus, лёгкий грузовик и малый автобус, которые по согласованным оператором правилам не относятся к `heavy`.

### `heavy`

Тяжёлый транспорт: medium/heavy truck, tractor-trailer, dump truck, full-size bus/coach и специализированная тяжёлая техника.

### `unknown`

Обязательный fallback, если объект:

- закрыт, размыт, обрезан или слишком мал;
- относится к спорной границе без согласованного правила;
- не входит в taxonomy;
- имеет confidence ниже утверждённого порога;
- является прицепом без однозначно видимого тягача.

## Требующие решения границы

- точные пороги массы/категории и источник ground truth;
- pickup и крупные SUV;
- cargo van против light commercial truck;
- minibus против bus;
- транспорт с прицепом;
- мотоциклы, велосипеды, спецтехника и сельхозтехника;
- классификация состава целиком или только тягача;
- правила для частично видимых объектов.

## Правила разметки

1. Использовать track-level label, а не независимый label каждого кадра.
2. Хранить исходную метку, финальную метку, причину решения и reviewer.
3. Спорные случаи направлять на review; не принуждать к одному из трёх классов.
4. Разделять train/validation/test по видео/локации, исключая утечку соседних кадров одного track.
5. Сохранять закрытый тестовый набор с дневными/ночными сценами, погодой, окклюзиями и разными углами.
6. Метрики публиковать по каждому классу, включая долю `unknown` и confusion matrix.

## Критерий утверждения

Владелец данных письменно утверждает определения, спорные случаи, минимальный confidence, классы вне scope и размеченный закрытый test set. До этого документ является только гипотезой.
