# Архитектурные решения

## ADR-001: Main-нода и независимые GPU workers

Статус: принято. Main размещает control plane и один GPU worker; удалённые workers идентичны по контракту. Масштабирование до четырёх GPU выполняется добавлением consumers без изменения API и БД.

## ADR-002: Одно видео целиком обрабатывает один worker

Статус: принято для первой версии. Видео не делится произвольно между GPU. Это упрощает tracking, line crossing, идемпотентность и восстановление.

## ADR-003: Объектное хранилище для видео

Статус: принято, реализация заблокирована отсутствием S3. API выдаёт multipart-сессии, но не проксирует файлы 3–4 ГБ. Originals неизменяемы; ключи уникальны; derived/results имеют версию pipeline.

## ADR-004: Единственный путь публикации результатов

Статус: принято. GPU workers не имеют PostgreSQL credentials. Они публикуют immutable manifest и объекты; единственный `result-writer` проверяет manifest/SHA-256 и завершает транзакцию с уникальными ограничениями.

## ADR-005: At-least-once с идемпотентностью

Статус: принято. Повторная доставка допустима, дубликаты запрещены ключами `(video_id, pipeline_version)` и `(video_id, pipeline_version, result_type)`.

## ADR-006: Versioned model registry

Статус: принято. Production читает только `approved`; модель идентифицируется версией и SHA-256. `latest` запрещён. ONNX или исходные Paddle-веса являются источником, TensorRT engine — node-specific производным артефактом.

## ADR-007: External database как fail-closed stub

Статус: принято. Интеграция отключена и возвращает `not_configured/dns_nxdomain/retryable=false`. Известные HTTP URL не являются PostgreSQL DSN; запись запрещена до отдельного согласования.

## ADR-008: Docker Compose до появления оснований для Kubernetes

Статус: принято. Kubernetes в пилоте не требуется. Compose-файлы появятся на следующем этапе после установки Docker и согласования pinned images.

## ADR-009: Потоковая обработка

Статус: принято. Decode/inference/aggregation выполняются потоково; все кадры на диск не сохраняются. Scratch содержит только ограниченные временные артефакты задачи.

## ADR-010: Секреты вне Git

Статус: принято. В репозитории допустимы только placeholders и пути к secret-файлам. Постоянные S3 keys, пароли и приватные сертификаты запрещены.
